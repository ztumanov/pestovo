# Санаторий «Пестово» — Презентационный сайт с интерактивной CMS панелью

Современный, премиальный одностраничный веб-ресурс для санатория **«Пестово» (ФТС РФ)**. Веб-приложение полностью адаптировано под высокие требования визуальной эстетики, отзывчивости и включает в себя полноценную систему управления контентом (CMS / Панель администратора) с клиентским сохранением данных.

---

## 🚀 Стек технологий (Tech Stack)

Приложение построено на базе передовых инструментов веб-разработки:

*   **Фреймворк:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (с полной строгой типизацией данных).
*   **Сборщик:** [Vite](https://vitejs.dev/) (обеспечивает мгновенный запуск и сверхбыструю сборку).
*   **Стилизация (UI/UX):** [Tailwind CSS v4](https://tailwindcss.com/) — утилитарный CSS-фреймворк для безупречной адаптивности на любых дисплеях (Mobile-First дизайн, плавные hover-эффекты, единая цветовая палитра).
*   **Анимации:** [Motion](https://motion.dev/) (библиотека `motion/react`) для бесшовных переходов слайдеров, плавного открытия модальных окон и мягких декоративных эффектов.
*   **Иконки:** [Lucide React](https://lucide.dev/) — набор чистых геометрических векторных иконок.
*   **Инструменты оптимизации медиа:** Интегрированный клиентский сжатиль изображений на базе HTML5 Canvas (позволяет сжимать загружаемые через панель администратора фотографии «на лету» перед сохранением в память JSON-хранилища).
*   **Локальное хранилище данных (Persistence):** `localStorage` с автоматическим отслеживанием лимитов квоты заполнения браузера и валидацией данных.

## 💎 Реализованный функционал (Key Features)

### 🏨 1. Каталог номеров и мульти-галерея (Новинка!)
*   **Слайдер фотографий в модальном окне:** Возможность добавления **нескольких фотографий** к каждому номеру. В подробной карточке номера встроен интуитивный интерактивный слайдер с плавными анимациями смены кадров, стрелками навигации и индикаторами-точками (pagination dots).
*   **Управление фотографиями в CMS:**
    *   Реализован полноценный менеджер изображений: загрузка перетаскиванием (Drag & Drop), импорт файлов с компьютера или по URL.
    *   Возможность менять порядок картинок (назначить любую фотографию главной одним кликом) и безопасно удалять ненужные ракурсы номеров.

### 🛡️ 2. Панель управления (Admin CMS)
*   **Общая информация:** Редактирование телефонов, факса, email, адреса санатория в реальном времени.
*   **Интерактивный медиа-редактор главного экрана (Hero Section):**
    *   Возможность загружать новые фоновые фото или видеоролики MP4/MOV.
    *   Встроенный загрузчик слайдов главного баннера.
*   **Управление номерами (Rooms CMS):** Добавление, удаление и детальная настройка каталога номеров (изменение цен, площади, спальных мест, вместимости, вида из окна, удобств и неограниченная загрузка фотографий).
*   **Управление программами лечения:** Редактирование каталога медицинских и оздоровительных программ, списка показаний к лечению и загрузка обложек.
*   **Управление услугами:** Интегрированная панель редактирования стоимости и описаний дополнительных курортных услуг (СПА, бильярд, пляжная зона, прокат).
*   **Отзывы, Новости и FAQ:** Динамические списки с возможностью публикации новостей, добавления отзывов гостей и актуального часто задаваемых вопросов.
*   **Умное клиентское сжатие (Client-Side Compression):** Автоматическое понижение разрешения картинок (downscaling до 1000-1200px) и рекомпрессия качества JPEG (до 75-80%) исключает переполнение лимитов `localStorage` (исправлена проблема «ошибок сохранения тяжелых фотографий»).
*   **Сброс системы:** Кнопка безопасного возврата интерфейса к дефолтному состоянию санатория.

### 📜 3. Разделы документов и лицензий
*   Полноценная страница документов с разбивкой по категориям (Служебные, Охрана труда, Лицензии на медицинскую деятельность, Прейскуранты).
*   Встроенный PDF-просмотрщик и возможность скачивания официальных файлов.

### 🍃 4. Высококачественные медиа-ресурсы
*   Использование надежных и быстрых Royalty-free видео-петель и профессиональных рендеров на главном экране. При сбое сети активируются автоматические статичные постеры-заглушки для непрерывности работы интерфейса.

## 🔧 Запуск проекта локально (Local Installation)

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Запустите dev-сервер в режиме горячей перезагрузки:
   ```bash
   npm run dev
   ```

3. Для сборки оптимизированного продуктового билда:
   ```bash
   npm run build
   ```
