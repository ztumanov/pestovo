# Веб-приложение Санатория «Пестово» ФТС России

Репозиторий содержит исходный код официального веб-приложения ФГКУ «Санаторий «Пестово» ФТС России». Проект разработан для обеспечения удобного информирования отдыхающих, бронирования услуг, интеграции с внутренними медицинскими/административными системами и повышения качества обслуживания.

---

## 🚀 Основной функционал

* **Информационный портал:** Полная информация о санатории, номерах, лечебных программах, ценах и инфраструктуре.
* **Система бронирования:** Онлайн-заявки на бронирование путевок и выбор категорий номеров.
* **Личный кабинет отдыхающего:** Просмотр расписания процедур, назначений и истории посещений.
* **Интеграция:** Обмен данными с внутренними информационными системами санатория (СУБД, медицинские модули).
* **Панель администратора:** Управление контентом сайта, обработка заявок, выгрузка отчетности.
